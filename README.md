# Manuel d'utilisation de Lemurix

Bienvenue dans Lemurix. Ce guide vous explique comment installer, utiliser et dépanner l'application pour les versions de distribution au format .exe et .msi.

## 1. Prérequis

Avant l'installation, vérifiez les points suivants :
- Un ordinateur sous Windows 10 ou Windows 11
- Un accès administrateur si l'installation doit être réalisée pour tous les utilisateurs
- Un espace disque disponible suffisant pour l'application et ses données
- Une connexion Internet si vous souhaitez installer les mises à jour ou utiliser des fonctions en ligne

## 2. Installation avec le fichier .exe

1. Téléchargez le fichier d'installation `Lemurix-setup.exe`.
2. Double-cliquez sur le fichier.
3. Si Windows affiche une fenêtre de sécurité, cliquez sur "Oui" pour autoriser l'exécution.
4. Suivez les instructions de l'assistant d'installation :
   - Choisissez le dossier d'installation
   - Acceptez les conditions d'utilisation si demandé
   - Cliquez sur "Installer"
5. Une fois l'installation terminée, cochez la case "Lancer Lemurix" puis cliquez sur "Terminer".

## 3. Installation avec le fichier .msi

1. Téléchargez le fichier d'installation `Lemurix-setup.msi`.
2. Double-cliquez sur le fichier `.msi`.
3. Si nécessaire, confirmez l'autorisation d'installation.
4. Suivez l'assistant d'installation en choisissant :
   - Le dossier d'installation
   - Les options d'installation proposées
5. Cliquez sur "Installer" puis sur "Terminer".

> Remarque : si l'installation via `.msi` est bloquée, ouvrez l'installateur en tant qu'administrateur.

## 4. Première utilisation

Après l'installation :
1. Ouvrez Lemurix depuis le bureau, le menu Démarrer ou la barre de lancement.
2. Si l'application demande une configuration initiale, renseignez les informations demandées.
3. Connectez-vous si un compte est requis, ou poursuivez en mode local si disponible.
4. Prenez connaissance de l'interface principale et des options disponibles.

## 5. Utilisation courante

Selon la version de Lemurix, vous pourrez :
- Ouvrir et gérer vos projets ou fichiers
- Accéder aux paramètres de l'application
- Configurer les préférences utilisateur
- Vérifier les mises à jour disponibles

Pour une utilisation optimale :
- Gardez l'application à jour
- Sauvegardez régulièrement vos données
- Vérifiez les permissions demandées par l'application

## 6. Désinstallation

Pour retirer Lemurix de votre ordinateur :
- Ouvrez "Paramètres" > "Applications" > "Applications installées"
- Recherchez "Lemurix"
- Cliquez sur "Désinstaller"

Vous pouvez également utiliser le programme de désinstallation fourni par l'installateur.

## 7. Dépannage

Si vous rencontrez un problème :
- Vérifiez que votre système respecte les prérequis
- Redémarrez l'ordinateur puis relancez l'application
- Désactivez temporairement votre antivirus si l'installation est bloquée
- Téléchargez à nouveau l'installateur si le fichier est corrompu
- Contactez le support si l'erreur persiste avec le message exact affiché

## 8. Notes importantes

- Les fichiers `.exe` et `.msi` sont des formats d'installation compatibles avec Windows.
- Le fichier `.exe` est généralement plus simple pour un usage standard.
- Le fichier `.msi` est souvent privilégié pour des déploiements en entreprise ou administrés.
- Si vous avez besoin d'une version portable ou d'une installation spécifique, consultez la documentation fournie avec la release.

Merci d'utiliser Lemurix.
